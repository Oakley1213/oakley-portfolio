01

起心動念

隨著程式與英語能力逐漸成為兒童學習的重要能力，現有資源仍存在入門門檻高、內容缺乏吸引力等問題。我們因此從學生與家長的需求出發，思考如何打造更容易開始的學習體驗。

  • 29%

    認為程式內容過於複雜

  • 26.3%

    對學習程式缺乏興趣

  • 45%

    家長認為現有平台內容枯燥

如何降低程式學習的入門門檻，並透過互動與遊戲化提升孩子的學習動機？

02

使用者研究

前期透過線上問卷蒐集不同年齡學生與家長的學習經驗，並依調查結果，將核心使用者收斂為國小程式初學者。

  • 線上問卷調查共 244 份有效回覆
  • 調查對象國小至高中學生及家長

學生端洞察

  • 47%

    偏好小遊戲與闖關活動

  • 34%

    偏好動作類遊戲

洞察

單純閱讀教材較難維持兒童的學習動機，具目標與即時回饋的活動更容易引導孩子持續參與。

設計回應

將學習內容拆分為短任務，加入故事引導、闖關機制、角色陪伴與即時答題回饋。

家長端洞察

  • 70%

    希望增加實際操作

  • 65%

    接受遊戲化學習

  • 40%

    認為每次一小時較合適

洞察

家長重視孩子是否能實際練習，也期望課程具備適當的學習時長與清楚的學習成果。

設計回應

每個學習單元加入互動練習、課後測驗與進度紀錄，讓孩子能立即應用所學。

03

從限制裡找機會

現有平台不是不夠多，是沒有一個同時處理「中文介面」與「玩得下去」。

  1. A

    故事啟發，提問思考

    用生活比喻帶出標籤概念——粗的像電線杆、斜的像溜滑梯，先有畫面再有語法。

  2. B

    課後遊戲，小試身手

    每個單元收在一題選擇題，答錯不扣分，只給回饋，降低出手的門檻。

  3. C

    IP 設計，學習不無趣

    四隻角色貫穿全站，把冒險地圖變成孩子看得懂的學習進度。

04

資訊架構：從 5 個分類收斂為 3 條核心路徑

初版同時包含學習、論壇、職涯探索與會員功能，但功能範圍過廣，也分散了兒童程式入門的核心目標。因此，我們依據問卷洞察與開發時程，將架構收斂為首頁、學習專區與會員專區三條主要路徑。

取捨依據

  1. 使用者需求

    優先回應孩子容易開始、實際操作與持續獲得回饋的需求。

  2. 核心任務

    將主要流程集中在「認識平台 → 進入課程 → 完成練習 → 查看進度」。

  3. 開發可行性

    在有限的專案時程內，優先完成能形成完整學習體驗的核心功能。

延後至後續版本

  • 論壇
  • 職業介紹
  • JavaScript 課程
  • 點數存摺

我們不以功能數量衡量完整度，而是優先確保孩子能順利完成一次完整的學習循環。

05

從線框到視覺系統

在進入高擬真設計前，我們先透過線框稿梳理內容層級與學習節奏，再建立適合兒童使用者的色彩與字體規範。

Wireframe｜先建立完整的學習流程

線框階段將首頁與學習頁設定為核心內容。首頁先協助使用者理解平台定位與特色，再透過明確的行動按鈕進入學習專區；學習頁則依照「引導思考、概念說明、重點整理、互動練習」安排內容順序。

理解平台價值 → 選擇學習主題 → 引導思考 → 理解概念 → 完成練習

Visual System｜讓學習更容易親近

Color System｜以高彩度建立活潑感

以黃色作為主要背景色，營造明亮、活潑的學習氛圍；紅、藍、綠、粉紅與紫色則延伸至角色與不同內容模組，協助建立辨識度。介面中的學習內容使用白色或淺色區塊承載，並搭配深色文字，避免高彩度背景影響閱讀。

  • 黃色：建立明亮、具有活力的主要場景
  • 角色色：區分角色與不同內容模組
  • 淺色內容區：提升文字與操作元件的可讀性

Typography｜兼顧親和力與閱讀層級

選用獅尾圓體 Swei Gothic CJK TC，圓潤的筆畫能呼應角色插畫與兒童學習情境。標題使用較高字重建立層級，內文與說明文字則使用中等字重，讓較長的課程內容維持清楚易讀。

  • Black／Bold：頁面標題與重要訊息
  • Medium：內文與課程說明
  • Regular：輔助資訊與次要文字

從內容層級、學習節奏到視覺語言，所有設計都回到同一個目標：降低兒童開始學習程式的門檻。

06

從資訊堆疊到清楚引導：首頁的四次迭代

首頁歷經四輪設計迭代，逐步改善資訊層級、視覺一致性與學習路徑，讓孩子能更直覺地理解內容並開始學習。

  1. v1｜資訊層級不明確

    內容雖已完整排列，但各區塊的視覺權重過於接近，缺少明確的閱讀順序與行動引導。

  2. v2｜建立學習路徑

    導入冒險路徑串連內容，嘗試建立閱讀順序；但折線造型較生硬，與圓潤的角色風格缺乏一致性。

  3. v3｜統一視覺語言

    將折線改為曲線，讓路徑與角色造型更一致，並加入中英雙語標題；但首頁承載的內容仍偏多，主要行動不夠突出。

  4. v4｜聚焦主要任務

    減少非必要內容並增加留白，將畫面收斂為一條主要學習路徑，讓「Start Now」成為清楚的主要行動入口。
